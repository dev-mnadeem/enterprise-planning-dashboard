# 📦 Adinkra ERP - Web App

## Getting Started

Clone the repository and navigate to the folder:

```bash
git clone https://github.com/Vecktor-Tech/Adinkra-FE.git
cd Adinkra-FE
yarn
#❌Don't use npm
```

## Development Guidelines
```bash
- Always cater the exception handling to prevent the app from crashing at any point.
- Use optioinal chaining while destructing an object i.e: User?.info?.name
- Keep the reusable components in /src/components/common
- Follow the default export structure
- Before committing the code, run "yarn precommit"
```
